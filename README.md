Networking and Data Communication Project

Repository ini berisi dokumentasi konfigurasi layanan jaringan pada Ubuntu Server dalam lingkungan virtual

Layanan

* DHCP Server: Memberikan IP otomatis ke client
* DNS Server: Menerjemahkan domain ke IP address
* NAT: Menghubungkan jaringan private ke public
* Web Server: Menyediakan layanan website
* FTP Server: Transfer file antara client dan server
* Mail Server: Mengelola pengiriman dan penerimaan email

Lingkungan

* Ubuntu Server (server)
* Ubuntu Desktop (client)
* VMware Workstation 17 Pro
